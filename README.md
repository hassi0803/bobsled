# BOBSLED 🛷

一人称視点で滑るボブスレーゲームです。ブラウザでそのまま遊べて、スマホにも対応しています。

**▶ 遊ぶ：** https://＜ユーザー名＞.github.io/＜リポジトリ名＞/

## 特徴
- プッシュ → 乗り込み → 操縦まで、本物の流れを再現しています
- カーブでは遠心力で壁を勝手に登ります。高い位置のまま出口に来ると転倒します
- 長野スパイラル（1998年大会コース）を再現したコースを収録しています
- 区間タイムでコースレコードとの差を表示します
- 全体ランキングと、合言葉で仲間内だけのグループランキングがあります

## 操作
| | キーボード | スマホ |
|---|---|---|
| プッシュ | SPACE 連打 | PUSH ボタン連打 |
| 乗り込み | ↓ | 乗り込みボタン |
| 操縦 | ← → | ◀ ▶ ボタン |
| ランキング | L | 🏆 ボタン |

## ファイル
- `index.html`：ゲーム本体です。外部のライブラリは使わず、このファイル1つで動きます
- `firestore.rules`：ランキングに使う Firebase のセキュリティルールです
